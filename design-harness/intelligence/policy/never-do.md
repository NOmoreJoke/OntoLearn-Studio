## Rule

1. **禁止单页瀑布流堆叠**：门户视图（项目库、学习路线图、模型设置）与业务工作台（01–08 模块）必须分屏切换，禁止同屏纵向堆叠超过一个一级视图。
2. **禁止右侧双侧栏并排挤压**：`MentorPanel`（课程导师）与 `AgentPanel`（AI 助手）必须共享右侧单一 `320px` 辅助栏并以 Tab 切换，禁止并排出现第四栏挤窄中间编辑器。
3. **禁止渲染层组件 CSS 裸写 hex**：所有颜色必须来自 `tokens.css` 语义变量。
4. **禁止同屏多个同等权重主动作**（PRD §8.3）：每个引导画面有且仅有一个视觉最高优先级 `--accent-primary` 主按钮，次要操作使用描边次按钮或幽灵按钮。
5. **禁止残留过期“待开发 / 待实现”占位海报**：已合入实现的 6 大模块不得再展示“待开发”卡片误导用户。
6. **禁止纯靠颜色区分状态**（PRD §8.9）：已通过、已过期、待确认、失败、暂停等状态必须同时带有文字标签或图标。
7. **禁止用隐藏导航替代响应式**：`390px` 视口下必须提供可点击的顶部菜单抽屉与导师抽屉按钮，不得简单 `display: none`。
8. **禁止开发诊断喧宾夺主**：打开项目进入工作台后，“检查本地引擎连接”诊断面板不得压在编辑器顶部，应收敛为侧栏底部状态指示（异常时显式告警）。
9. **禁止缺失交互与边界态**：所有新组件与精修页面必须覆盖 `default / hover / active / focus-visible / disabled` 与 `empty / loading / error / full`，长文本与长 IRI 必须正确换行或截断展开。
10. **禁止未过真实双视口核查即交付**：交付前端界面改动前，必须实测 `1440px` 与 `390px` 渲染视图确认无横向滚动条、重叠或裁切。

## Why it holds

这 10 条禁区直接对应本轮审计暴露的瀑布流、双栏拥挤、过期占位及 PRD §8.1–8.9 强约束，能被静态单测与人类/视觉复核双重核验。

## When it doesn't

无例外；确有特殊全屏图表场景需突破某一条（如局部关系图临时全屏），须在 PR 中写明豁免范围并保持退出按钮键盘可达。
