固定集成代码：`5f910b52c69d86a1076b2032e5d3c63e715947f3`（I01–I04 已批准集成基线）。本入口用于确认真实 Electron → preload → 主进程 → 内置 Python 引擎通信；新业务页面请使用同级 browser 验收入口。

## 入口

在 Finder 打开本目录，双击 **OntoLearn Stage Acceptance 20261022.app**。此包无需 Node.js、Python 开发环境或 API key。仅适用于当前构建的 macOS Apple Silicon；不是 Windows 安装包。

包内 `package.json` 与 macOS `Info.plist` 已核对为独立应用标识和名称；主进程使用 Electron 默认 `userData` 且没有自定义覆盖，按此配置应与 `OntoLearn Studio` 的默认数据目录分开。此次未启动 Electron，实际运行路径尚未实测。这只改变打包元数据，业务源码和依赖锁保持固定基线原样。包无开发者分发签名且未公证（主二进制仅 linker adhoc 签名，包资源未封存签名）；如系统阻止启动，请保留系统提示并记录“环境阻断”，不要将其记作业务测试失败或通过。

## 操作步骤与预期

1. 启动后应出现“开发概览”和“检查本地引擎连接”。不要期待六个业务模块导航已接通。
2. 点击 **检查本地引擎**。预期显示“本地引擎已连接”、引擎版本与协议版本。若显示错误，记录界面上的“发生了什么／为什么／如何修复”，不要提供个人数据库或凭据。
3. 再次点击同一按钮。预期仍能得到真实连接结果，按钮不永久停在检查中。
4. 正常退出应用后，手动再次打开并重复第 2 步。此项由用户实际操作确认；构建交付时未自动启动窗口。
5. 检查六个模块卡片。预期保持“待开发”，页脚说明项目编辑、自动保存、模型调用与六模块业务尚未接入。这是准确的现有集成边界。

后台任务读取、取消、提交点和摘要组件已存在，但只有主进程选中真实受信项目及已有任务时才显示。干净阶段包没有项目创建或业务任务发起入口，因此不应出现任务；**无任务不能证明取消、崩溃恢复或业务计算通过**。本包不使用测试启动参数注入任务，不把测试工作负载冒充产品能力。完整任务恢复留待隔离环境和实际业务接线验收。
