# OntoLearn Studio 阶段验收包 · 2026-10-22

先体验 `browser/index.html`，再按需检查原生桌面包。两者的验收范围不同：浏览器入口展示新模块真实组件的本地交互；桌面包检查已批准集成代码与内置 Python 引擎的真实通信。两者均不代表完整产品或新模块指定双审通过。

## 入口与使用顺序

1. 在 Finder 中双击本目录的 **打开阶段验收.command**，或用浏览器打开 `browser/index.html`。页面完全离线，不需要安装依赖、启动服务或填写 API key。
2. 按页面顶部的步骤检查四个模块：本体构建、本体查询、行为定义、离线学习。为每步选择“符合预期 / 发现问题 / 不适用”，在底部记录问题后点击 **下载验收记录**。刷新、切换模块和重置会影响内存草稿；刷新前先下载反馈。
3. 如需确认真实桌面引擎通信，在 `desktop/` 中找到 **OntoLearn Stage Acceptance 20261022.app** 并手动打开，按 `desktop/README.md` 操作。本包为 macOS Apple Silicon 未签名、未公证目录包；系统阻止启动时记录环境阻断。
4. 所有源码身份与校验在两个子目录的 `manifest.json`；本轮实际检查见 `verification.json` 和独立审查报告。不要把开发分支中其他版本的测试结果拼到本包。

## 本轮可确认内容

| 入口 | 可亲自操作 | 预期结果 | 证据边界 |
| --- | --- | --- | --- |
| 本体构建 | 搜索对象、切换表格 / 类树 / 局部关系图、编辑新概念表单 | 页面随选择和编辑变化；未接通的预览 / 提交不可用 | 现有组件 + 合成目录；不证明真实本体服务或保存 |
| 本体查询 | 选择类与字段、生成和编辑 SPARQL | 真实确定性编写器生成对应 IRI 的草稿；无模拟查询结果 | 真实草稿编写逻辑；没有真实查询执行、保存或分页 |
| 行为定义 | 编辑触发条件、安全动作与事件输入 | 本地草稿变化；试跑未接通，不生成虚构成功 | 组件交互；不证明行为算法、推理、提交、回滚或取消 |
| 离线学习 | 切换学习任务、阅读课程和术语 | 对应内容改变；没有无依据的完成进度 | 真实离线内容；没有真实检查、提示留痕或进度持久化 |
| 原生桌面 | 点击“检查本地引擎”，正常退出后重新打开再检查 | 实际 Electron / preload / 主进程 / 内置 Python 回包，显示版本 | 基础通信；没有业务项目创建或任务发起入口 |

合成示例仅用于本轮界面检查，不是正式项目、隔离副本或真实业务数据。需要真实执行或保存的主要入口保持禁用；课程检查入口可提示“暂不可用”，不会产生通过结果。不能把禁用或提示不可用视作功能已完成。

## 尚未完成

- 新组件没有接到统一正式 App 的项目 / Store / Job / 受信 bridge；浏览器和原生入口之间不传输项目状态。
- 真实项目新建、打开、保存、确认提交；本体服务编辑与往返导入；映射导入、查询执行与分页；质量校验与推理；行为执行与资源竞争；沙盘轮次；Agent / 模型；迁移和完整导出未由本包验收。
- 跨模块、取消恢复、原生窗口生命周期、双平台干净设备、签名 / 公证及发布验收未完成。本轮没有自动启动可见浏览器或 Electron 窗口。
- 新组件与新增验收外壳仍待指定模型审查。内部独立复核、构建或界面测试不能替代 ZCode / MiniMax Code 同版本双审。
