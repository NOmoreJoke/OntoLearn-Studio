# 阶段验收入口（2026-10-22）

**入口：双击同目录的 `index.html`，用 Chrome、Edge 或 Safari 打开。** 页面全部脚本、样式和合成数据已内嵌；不需要开发环境、网络或本地服务。不要打开 `entry.tsx` 或 `build/`。

这是从固定 Git 提交提取的四个现有真实 React 组件，外加独立验收导航与记录表。它验收界面、内存编辑与现有 SPARQL 编写逻辑；不是完整产品或真实业务执行器。界面顶部保留“合成样例”“待指定双审”标识。

## 操作与预期

1. **本体构建**：输入“传感器”查找概念；清空搜索并查看 Sensor；切换表格、类树、局部关系图；新建并编辑概念表单。预期：筛选与视图切换有效；预览、保存和提交没有接入，不能生成已保存结果。
2. **本体查询**：选择“传感器”、勾选“温度”，点击“生成可见 SPARQL 草稿”；编辑名称和文本。预期：草稿含类与属性 IRI；执行、保存、结果分页和取消不可用，没有模拟查询结果。
3. **行为定义**：编辑名称、触发事件、条件、安全动作和事件输入；添加再移除条目。预期：内存草稿随操作变化；试跑、真实隔离副本与行为执行服务未接通，没有伪造运行记录。
4. **离线学习**：切换学习任务、选择术语、展开技术定义。预期：内容切换；没有真实上下文的检查、提示留痕、进度及报告导出不应冒称通过。
5. 在每个步骤旁选择“符合预期 / 发现问题 / 不适用”，在页底填写操作与实际表现，再点击“下载验收记录”。记录为本地 JSON，**不会自动回传**。将该文件交给开发会话处理反馈。

## 数据与重置

全部项目、对象目录和行为身份是合成展示数据，不授予真实项目、数据库或隔离范围。课程文字来自固定已有内容文件。页面没有 Store、bridge、模型或网络请求，不写正式数据。草稿和验收勾选仅存页面内存；切换模块会重新装载该模块，刷新或关闭会清空所有本次记录。请先下载记录。点击“重置当前页草稿”只重置当前组件，不清除已填验收结果。

“下载合成样例”导出本入口的合成本体视图与查询目录，仅供核对展示输入，不能作为正式业务基线。

## 固定来源与复现

`manifest.json` 记录每个提取文件的 Git 提交、原路径、字节数、SHA-256，以及生成入口哈希。`snapshot/` 为从 Git blob 提取的源码，不直接读取活动开发树。合成目录与验收壳源码见 `entry.tsx`、`shell.css`。

本机复现：在本目录运行 `node build.mjs`。构建依赖默认使用现有 `OntoLearn-Studio/node_modules`；换目录时通过 `ONTOLEARN_BUILD_DEPENDENCIES` 指定已有依赖路径。构建不安装依赖、不启动服务器、不打开浏览器。最终交付的 `index.html` 自包含，可独立复制使用。构建使用现有 Vite / React，不修改业务源码、锁或公共契约。
