# Windows 与 macOS 支持要求

日期：2026-10-20（Asia/Shanghai）。来源：用户明确要求“开发的产品需要支持 windows 和 mac”。

## 已确认

- OntoLearn Studio 必须支持 Windows 和 macOS；两者都是产品目标平台。
- 后续设计、依赖选择、引擎打包及产品验收须覆盖这两个平台，不能用单平台验证替代双平台支持。
- 当前 Windows/macOS CI 门禁继续保留；CI 通过与正式产品支持验收分别记录。

## Q2 剩余待决及验证

产品目标平台已确认。最低系统版本、CPU 架构、参考设备、是否同时首发，以及签名、公证、安装与干净设备验证仍待明确或执行。本记录不替用户指定这些答案，也不表示双平台支持已经实现或验收通过。

## 与现有基线的关系

本记录补充 PRD V0.6 的 Q2。旧文档中“平台待定”的描述应结合本记录理解；归档 PRD 和历史评审保留原样。当前迭代的顺序、冻结候选和审查门禁不因本次需求确认而改变。
