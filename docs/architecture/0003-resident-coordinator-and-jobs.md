# ADR-0003：常驻协调器、任务与共享读取

日期：2026-10-20。状态：I04 实施采用，完整验收、外部双审和合并门禁见 [I04 状态](../reviews/I04/status.md)。基于已合并 I03 的 [设计](../iterations/I03/ADR-0003-design.md)；以下结论来自实际子进程、SQLite、传输及隔离窗口探针，最终候选证据在状态文档关联。

## 决定

采用一个 Python 常驻协调器，经严格 v2 JSONL 与 Electron 主进程通信。协调器持有 OS writer lease，JobStore 与 S1 使用同一 SQLite；正式修改、版本、失效、operation marker、receipt 和 job 提交证据同事务写入。隔离 worker 只计算，不持有数据库。重启先取得 lease 并隔离旧写者，再查持久证据；不因进程退出、最后轮编号或通知判断成功，不自动重放写操作。

主进程负责进程监督、可信项目、请求关联和视图订阅。通知只作提示，缺口、重连及 revision 变化通过权威查询恢复；页面卸载只解除订阅。preload 仅暴露业务命名的读取、取消和订阅方法，renderer 不得创建任务、指定路径或调用通用 IPC。

每个 stdio 会话最多接受 65,536 个唯一请求（包括 hello 与控制 ping），会话内保留全部 ID 防重放，不以 LRU 淘汰放行旧 ID。超限或重复 ID 使该会话关闭；常驻指进程复用，不承诺无限请求或任务无中断。主进程按三次有界只读恢复建立新会话，已提交 marker/receipt/历史保留；未提交工作按持久证据失败为 ENGINE_EXITED，不续跑。守护读取线程使用原始文件描述符读取，避免父进程仍持有 stdin 时退出争用 Python 缓冲锁；正常 worker 终止和 Store 清理仍执行。

统一规范、错误目录和公共正反例由 TS/Python 两端消费。握手检查 registry 原始字节 SHA，包内显式包含规范、Python 适配器和锁来源。任务身份、输入、确认、计划、依赖与实现来源完整绑定；不可变结果和列表使用固定集合与持久游标，不以缓存 TTL 代替身份校验。

## 运行依据与修订

真实探针已验证同 PID 多次健康查询、忙碌 worker 期间取消和心跳、单 worker 故障隔离、原子提交及已提交轮次保留、重连查询和重建订阅。独立审查发现的总期限遗漏、退出等待取消、终态后帧、可信错误来源、环境继承及订阅竞态已据真实反例修复。当前源码与 Linux 打包应用均在虚拟显示实际触发 renderer 崩溃和可见聚焦窗口无响应，并操作原生提示；证据关联于 I04 验证摘要。

修订 I03 的 null-session 错误分支，仅允许未握手非 hello 的 HANDSHAKE_REQUIRED / VERSION_INCOMPATIBLE；不放宽成功和其他错误。可信 binding 的缺字段、非法类型和状态安全拒绝。两项修订归 I04 新候选完整双审。

## 边界与拒绝的替代

不另存第二份权威终态，不信任客户端自报依赖，不自动续跑写任务。Linux RLIMIT_AS、Windows JobObject 与 Darwin RSS 采样分别验证；Darwin 不是硬内存上限，存在采样间超量边界。当前测试负载不能证明未来语义原生库的资源隔离。

仅开放已实现基础设施方法；测试逐轮任务不登记产品能力。F6 只验证真实任务、轮次、摘要与结果分页基础设施，E.2/E.5/G.4/FR-704 业务执行及页面、I05 语义、I06 网关仍待其正式集成。I01 R6 历史增长保留开放，未据合成测量承诺性能。原 Q2/Q3/Q5/Q6/Q7/Q8/Q9 决策与签名安装验证不由本 ADR 替代。
