## 决策和退出记录

截至本记录，未收到 Q6 本体＋技术负责人的逐项采用 / 范围修订 / 候选淘汰结论。所有“待判断”均保持开放，未改变 PRD，也未授权业务能力上线。完成判断需填写每一行的决定、对应需求版本、负责人来源、必要实现和实际证据；不能只填统一“Q6 未定”。

淘汰 / 修订的共同触发是：获准的明确代表样例无法满足且适配不能修复；实现必须扩大未批准标准深度才能满足；或真实打包 / 外联控制 / 确定性结果 / 原始来源无法成立。此时保留失败样例与测量，重新评估候选组合，不隐去失败或缩小原验收。

数值工程上限（文本、图、匹配 / 工作预算、未来 worker 总时限和内存）另受 Q5 与 S2 约束，不是 Q6 已批准业务容量。当前 macOS arm64 开发包也不代表 Q2 首发平台 / 签名 / 干净设备合格。状态和实际候选版本只维护在 status.md；本表不另造里程碑完成结论。
