## 3. 唯一可信链及版本

3. T01真实owned worker获得原Job context与有界物料；I05单次生产，原L在实际allocator创建点另捕获，原defs/Catalog在实际规范化点捕获；全部false/true、disabled、ordinal和完整source仍由原计算产生。
4. 只有整次计算、投影、rows、输出界与成功complete/正常child exit均通过且原Job仍可提交，T01原writer才能同事务保存完整artifact、不可变origin、result与terminal。失败/取消/late不发布前缀。

## 8. 编码、传输与预算闭包

### 8.1 保持原界，不能把B/Q当一帧

符号：B=payload_json+rows_json≤8388608；Q=input_preimage+source_preimage≤16777216；N≤100且N=max(1,原rules数)。Turtle原输入≤1048576；structured原input编码≤8388608。原17 L逐Unicode-ID稳定排序/divmod，disabled仍占槽，ΣW=16777216、ΣI=ΣO=262144、ΣF=1024、Σhead=16384、Σtrace=8192、Σbindings=1024，未改。

另设P为origin/capture数据metadata（不含大B/Q），按固定字段和两组完整ID/17L记录先界，拟cap16MiB；单次B+Q+P≤40MiB。P界来源须在供应实现逐字段/编码证明，不能允许任意extra JSON；不是新业务容量承诺。origin上游snapshot/定义body/blob既有门另计，不偷并入P。
