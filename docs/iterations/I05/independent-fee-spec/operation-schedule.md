# 五 operation 的逐动作补充合同（全为提案）

本表是最小新增收费点，不是旧产品动作追踪。每格的 ITEM/INPUT/OUTPUT/SCAN/COPY/HASH/HOLD/RELEASE/BLOCK 使用 specification 的 exact 公式。`len`指实际角色bytes/完整字段，不以asset JSON长度替代native前像。现有 exact 固定 D 票仍只扣一次，其内部项目用包含关系核覆盖，不能再叠扣。所有阶段结束都需已预付receipt/cleanup。未知长度/block/witness须pending，不补0。
