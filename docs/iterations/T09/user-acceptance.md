# T09 真人学习验收方案与空记录

依据 PRD 11.2、12.1。至少 5 名未参与开发且缺乏本体经验的真实用户；邀请、对外招募与消息须另有明确授权，本任务未发送邀请，未填造数据。

使用冻结的最终完整产品候选，在没有预配模型 API、没有开发人员代操作的条件下，逐项完成安装/案例打开、本体编辑及RDF核对、CSV稳定身份/重跑、查询及空结果、约束失败/修复与规则依据、行为触发/不触发/幂等、E.5场景对比/重放、迁移任务与报告导出。逐步记录实际工具证据、数据版本、卡点、口头解释、外部文档和开发协助。

每位用户分别记录各任务操作完成与独立迁移成功；提示1–3级归部分提示，4级归完整示范，Agent完整修改单独标记。任何辅助不算该次独立迁移成功；完整代做负例允许操作完成，但必须保持独立迁移失败并出现在报告中。

分母为实际参与完整预定流程的合格用户，退出/未完成保留原因，不静默排除。至少5人、核心案例完成比例至少80%；按实际人数向上取整到所需完成人数（5人为4人）。独立/部分/完整示范分列，不把80%解读为独立掌握率，也不外推总体效果。迁移与Agent代做负例另列。若调整样本或流程，先记录新的口径与理由。

空记录字段：candidate SHA、manifest SHA、平台、匿名用户编号、非开发/新手资格、各任务起止、操作完成、提示最高层级、Agent辅助、独立迁移成功、工具依据/输入版本、卡点/协助、退出原因、报告文件与安全检查。真实结果尚未取得，空记录不计入样本。

严重阻碍核心流程的问题须发布前修复并重验；本方案不自行授权缩减首版范围。
