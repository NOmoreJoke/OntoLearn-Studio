# T10 报告文件发布服务

新增私有 `main/project-transfer/prepared-report-file.ts`。它只管理一份已渲染 HTML 文件的临时发布，不读取 Store、不持有项目权威状态、不注册 IPC 或新的公共契约。

## 输入和接点

`PreparedHtmlReportFile(projection)` 在任何选择器/文件操作前严格校验并固定 UTF-8 内容、字节数和 SHA256；源对象后续变化不会改变产物。内容不对外暴露可变 Buffer，公开 metadata 冻结。

`save(mainOwnedPicker, {signal})` 只调用由主进程提供的文件选择适配器。适配器返回用户实际选择的目录/文件名，不能改为 renderer、包或模型提供任意系统路径的入口。选择结果经过 strict schema、绝对目录、HTML 后缀、保留名及路径字符检查。当前测试选择器是明确的合成适配器；没有调用或验证真实 native picker。

正式接线仍需 owner 提供已批准的凭据安全业务投影、当前可信窗口/项目/代次校验和真实文件选择授权。当前输出继续带内部预验标识，不开放为产品正式导出。

## 提交与异常

1. 规范化已选目录；在该目录新建独占私有临时目录及 `wx+` / 0600 文件。
2. 写入固定内容并 sync；发布前通过保留句柄有界读取，核验完整字节、长度和路径身份。
3. 同文件系统 hard link 原子发布，禁止覆盖既有文件、目录或最终符号链接；竞争创建目标时失败，保留原目标。
4. link 返回成功即记录已发布；之后回调失败或取消不能倒退成普通失败/取消。目录 sync 不可确认时仍报告文件已发布，同时单独显示耐久性未确认。
5. 若 link 操作自身响应不明，则以自己临时文件的 inode 读回目标。无法读回时保持 publication-unconfirmed，禁止再次保存；显式读回后才决定已发布或目标当前不含该产物。不把“当前未观察到”解释为“历史上从未提交”。
6. 清理只处理自己记录身份的临时文件和空目录，不递归删除未知文件。清理不完整据实返回 pending；阻止无界新暂存，提供单飞清理重试。

每个实例只允许一次成功发布；并发保存拒绝。返回值不含系统路径、业务正文、原始异常或堆栈。该服务没有跨进程提交日志或自动启动清理器；应用重启后的原生选择、临时资源生命周期和完整项目恢复仍由正式集成验收覆盖。

服务不声称能阻止同 UID 的外部进程持续修改用户文件。发布前检查用于验证当前受控暂存，不是新的 OS 文件隔离保证；安全包解析器也不能据此获得文件系统写权限。

## 实际验证范围

文件测试使用真实临时目录与 Node fs，覆盖完整文件内容及 hash、取消/异常、既有文件/目录/符号链接、目标竞争、暂存路径替换/原地改写、重复及并发保存、清理保留未知文件、不确定终态读回。命名故障测试仅包装实际 link 的回执和一个真实目录句柄的 sync，明确是故障注入，不宣称测得真实 OS 丢确认或硬件掉电。

报告 `<pre>` 使用静态子 `<span>`，避免 HTML 对首个 LF 的特殊删除。浏览器预验包含前导 LF 和全部脚本/事件/外部资源攻击文本，打开由本服务实际发布的 HTML；真实 native picker、App/bridge 和双平台包内路径另行验收。
