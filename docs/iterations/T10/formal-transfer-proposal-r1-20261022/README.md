## 不可更改的需求原义

依据固定PRD：FR1000三类必需集合全部保留，四项可选内容分别明确选择；缺当前断言**或**来源所有权不能称可恢复当前的完整包。无原始文件不自动降模板；只能说明不能直接重跑对应映射。恢复当前、逐映射重跑、逐运行重放分开判断。文件/hash齐全不能证明业务恢复、来源真实或执行语义支持。

恢复必须保留人工事实、映射事实、source-row/owner/managed值、墓碑、生成版本与必要撤销引用；在设备B能继续编辑/查询、重新关联同源识别同样人工冲突，并按原规则撤销。源库整个SQLite或全祖先checkpoint复制均不能替代业务投影。合法当前状态所需的最小撤销闭包不等于全部运行历史；闭包与未选项冲突时拒绝并明确协调，不暗带、删引用或静默降模板。
