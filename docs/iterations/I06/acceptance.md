测试只使用合成数据。端口由 server.listen(0, '127.0.0.1') 专属分配并及时关闭，不启动产品 HTTP 服务。上表原核心单测使用凭据 doubles、不启动 Electron；新增 [实际 Linux 组合探针](platform/combination-isolated-probe.md) 在独立断网容器运行真实 Electron/safeStorage/私有仓库/持久审计/transport，有单独运行产物及来源摘要。内部资源保护数值不是 Q5 容量指标。

凭据身份追加反例：仓库主体/版本篡改、交换另一条有效密文、仓库 binding 额外字段均拒绝；解密内容为旧 raw-key、坏 JSON、未来内部格式、顶层或 binding 未知字段、非法 secret 时拒绝，无宽松兼容回退。四项身份反例已在旧实现实际失败，修复后的完整严格信封测试通过；详见 [凭据绑定内审](../../reviews/I06/credential-binding-review.md)。

等待/资源反例：受控时钟验证凭据及持久审计 promise 卡住后到期拒绝且接收端零请求；凭据恢复可复用未变化授权。四个等待占满时第五个请求不增加凭据读取、取消后容量可用。持续 503 完整断言两次相同请求后失败。真实 socket 假接收端读完请求但不响应时，总时限终止且只有一次接收，没有网络异常自动重放。这里只验证基础设施故障和内部保护上限，不证明业务容量或真实模型协议。

## 正式接入仍需关闭的项目

- I03 唯一维护者提供项目/资源/字段/快照 scope 身份与严格公共 schema；模型用途、隐私档、grant/preview、内部固定错误的公共映射、真实 capability 分类。当前本模块 zod 仅私有进程内参数，不是第三套 TS/Python 协议，也不能直接注册 IPC。
- 总控请求的 11 类受限错误 code/messageKey/safe params 需求已逐项整理为 [公共错误映射交接](public-error-requirements.md)，仅是供 I03 采纳的输入，不声明公共映射已批准或接线完成。
- I04 提供可信应用服务与任务生命周期：模型材料来源必须从已验证的只读权限、结果/版本引用派生。工具隐式读取、跨项目缓存、历史/摘要完整上下文不能自报降权；失败/过期/缺失依据传安全事实，不能声称工具成功。公共能力注册表不能把凭据/发送塞入 Python。
- I02/I04 共同提供可信 sender/mainFrame/document 与业务命名窄 bridge，重建后只查询/重连，不重放模型调用或写任务。正式接线须刷新包含依赖的 develop，再跑相同候选的运行联验和指定双审。
- 已完成私有 POSIX 密文仓库、持久 metadata-only 审计、实际 Electron factory 和隔离 Linux 组合；正式产品主进程注入仍待唯一 owner 交接。导出/项目/会话与普通日志真实排除凭据，并保留目标配置身份关联，仍需完整运行链验证。Linux 受测 backend/失败边界以组合证据为准；其他平台/Windows ACL/锁定/签名升级/干净设备不扩大通过。
- FR-806：真实存储保存不依赖模型成功，模型失败、取消、窗口重建仍保留既有数据；不得用本模块无 Store 接口或 mock 保存函数当作真实联验。
- FR-006/304/703/705/804、附录 C/D/E/G：不改领域失效、原子 ChangeSet、历史和场景语义；正式接入核对模型配置只撤销外发授权，不产生领域 staleReason。只有真实语义特定材料依赖 I05，不因它阻塞无关模块。
- 实际返回载荷按 Q9 选定受测协议严格解析；不把当前合成 `{model,parts}` 和字符串响应直接暴露到 renderer 或声明结构化输出/工具调用成功。
- 当前桌面禁用 GUI/native/HMR/外部审查应用自动点击。已用独立 Linux Docker/Xvfb/Keyring 实测组合；完整 e2e、其他平台和 ZCode/MiniMax 双审仍按总控隔离环境/预约门禁安排；不以 stub、隐藏窗口或替换模型绕过。
