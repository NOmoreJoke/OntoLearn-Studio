## 接受的方向

- 保留唯一有界 JSONL；64 KiB **原始字节**分块、序号校验、seal 重算完整长度/SHA，再签发严格版本化/归属校验的 sourceRef，方向与 broker/parser 无冲突。128 × 65536 = 8388608 字节，覆盖当前 8 MiB 文件上限；不是 128 个任意大小 frame 的授权。
- 保留 main-only 真实 picker、scope 对象身份、每次源 SHA 复验、XLSX 先检查字节再真实枚举/选表、两实际未终态 broker 操作及既有取消/迟到拒绝。inspection 不生成 proof，`readForCommit` 也不代表已获用户确认或已提交。
- 预览绑定来源、显式选项、解析表、映射定义、项目/领域基线与真实 Store 预览；最终映射写入另经用户确认，提交前复验主进程保管的实际 proof，最终映射写入 Job 仅消费经用户确认且绑定输入的封存快照。响应丢失后按 operation/receipt 对账，不自动重放写入。
- worker 接收同一受控 JSONL 的分块并 seal 后解析；不按 renderer 路径重开文件，不把解析搬进 coordinator 事件循环，也不扩大 MAX_FRAME、另开 HTTP 或使用任意 blob 代替受信来源。
