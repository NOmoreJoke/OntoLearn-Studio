## 执行与错误建议

建议 I05 同一受控Rule结构增加受限比较条件及多结论，先绑定三元组模式产生的变量，再评估比较，收集每次匹配的全部输出及共同依据。变量未绑定、未知operator、递归/否定/聚合/代码等继续拒绝；disabled规则可保留定义但不评估。

比较先以以上同型小整数正反例闭合原P0；跨numeric datatype提升/精度、语言标签、字符串排序、日期时区以及非有限/不兼容类型错误分类，仍需I05逐项给出的真实支持矩阵与Q6采用。此提案不把“错误”固定为某个新公共错误码，不擅自选定跨型转换；需通过唯一公共目录安全映射。合法但不支持必须明确不支持，不能返回通过或将比较跳过。

自定义输出严格只来自“断言＋RDFS”冻结输入；无规则输出反馈，无后置RDFS。多输出共享同一完整输入绑定，任一错误不得发布部分成功当前结果。全量结果集合比较、每条输出依据和输入/规则/语义版本同时核对；不得把这里expected填进实际结果/Store。
