# 跨设备、升级与回退比较规范

T01 的 SQLite/Store 与 T10 的项目包是唯一项目权威；T11 只比较只读证据，不直接写数据库，不实现第二种项目导入、恢复或迁移器。

准备 A/B 两台受支持干净设备、两个独立数据目录和同候选安装资产。每次运行从 T09 固定 manifest 指定的基线/重置操作开始；不能继承上一个用例状态。完整案例至少包含手工事实、映射事实、受管人工修改、来源/行/managed value/墓碑、当前和过期结果、不可变运行与已提交轮次、撤销依据、模型辅助标记。记录项目 revision、输入 snapshot、依赖向量、规则/行为/执行语义/引擎与锁版本。

A 导出前通过唯一正式读接口取得 `t11-comparison-v1` 完整快照；在明确选择的数据范围下由 T10 导出项目包，不带凭据和未选择会话。B 导入后先比较清单核心内容及完整规范数据，再实际继续编辑、查询、重新关联同一源文件后映射重跑、确认相同人工冲突、执行允许的撤销及沙盘重放。按 PRD 固定语义比较全部实体/事实/来源/结果/轨迹集合；不只核对条数、哈希摘要字段或界面截图。

`t11-comparison-v1` 必含 projectId、sourceSnapshotId、facts、definitions、ownership、mappingState、queries、results、history、rounds、undo、executionVersions、projectRevision。集合行统一为 `{id,payload}`，id为该层稳定唯一身份，payload保留所属领域完整原始内容；固定冲突/历史验收场景各层必须非空。独立冻结记录分别pin恢复和两方向源快照SHA，不能用相同假快照自证相等。所属领域负责人按稳定身份排序，保留轮次/动作顺序，规范化仅限设备绝对路径等与语义无关项且需记录映射；不删除来源、ownership、版本、过期状态或冲突来取得相等。原始设备导出同时保留，适配器待T01/T10正式接口交接后实现，不猜接口。恢复要求完整规范快照相等；导入产生的新操作身份另列，不混入源项目快照。

反例必须真实执行：只含定义/缺事实或来源元数据的包标为模板；缺原文件可恢复当前项目但不可直接重跑，重新关联才恢复重跑；缺输入/配置/行为规则/语义版本不可标可重放；缺外部依赖明确提示；完整 Agent 代做迁移不得计独立学习成功。以上均保留 expected/actual 完整 JSON。

升级前用正式备份接口生成新路径备份并实际恢复检查；失败迁移必须保持之前完整已提交数据。卸载确认安装文件、项目、应用私有凭据设置各自边界，记录保留/删除选项及用户确认；不能默认删除项目。回退先停止写入并保留新版本数据副本，核对旧版能读的格式，再用真实上一版签名安装器和兼容备份恢复。旧版不能读取新格式时应拒绝直接打开，只能恢复兼容备份；不能用破坏性降级或覆盖唯一项目模拟成功。

双向 Win→Mac 与 Mac→Win 分别留完整报告，绑定实际源/目标设备、candidate/T09/安装包 SHA和时间。`RECOVERY_*`/`MIGRATION_*` checks 在核验器中是强制覆盖，不代表其中任何真实验收已经执行。
