# 指定结果投影的内部细码补充

此表对应 `project_validation_scope` 的新来源分支；承接 v3 固定细码，不修改共享公共目录或业务方法。实际所选载荷真实性 / 权限 / 内容摘要 / 结果与快照 / 生产实现的权威绑定仍在 I04。此处的生产输入规范摘要只比较本次完整图与规则计划，不是 I03 blobRef 的字节摘要，不能自报授权。

| 内部细码 / 实际来源 | 安全去向与边界 |
| --- | --- |
| REASONING_SOURCE_MISMATCH | 私有生产上下文缺失、字段 / 有限语义版本 / 全部原断言 / ontology / 生产规则计划摘要不一致。可信适配器或读取层违约→INTERNAL_ERROR；不猜测哪个用户选择有错，不重算替换原结果。 |
| REASONING_RESULT_INVALID | 缺所选载荷、固定结构 / RDF 项 / 结果与依据覆盖 / 规则绑定 / 原始依据 / 角色 / 警示等不一致，或所选项 Unicode 非法。可信载荷损坏 / 适配器违约→INTERNAL_ERROR；不携带原值或解析异常。覆盖一致不独立证明 RDFS 结论或全局完备性。 |
| UNSELECTED_REASONING_PRESENT | asserted-only 选择却由适配器附带推理载荷或生产上下文→INTERNAL_ERROR。公开参数层若已证明用户参数形状冲突，由其按既有 INVALID_REQUEST 拒绝；纯投影器不证明用户归责。 |
| PROJECTION_RESULT_LIMIT | 实际最终事实 / 公理视图量超过工程预算→RESOURCE_LIMIT / semanticResult，非输入或单页。真实分图测试临时降低相应预算以触发此执行分支，不改业务容量决定。 |
| WORK_LIMIT（新增来源） | 载荷输出、依据及输入项累计检查预算超限→RESOURCE_LIMIT / semanticWork。复用既有安全类别，不称为最终结果量、内存或执行墙钟。 |
| INVALID_UNICODE（新增来源） | 原图 / 规则生产上下文摘要无法 UTF-8 编码→固定安全错误；外层仍按实际可信生产者 / 入口区分内部错误与用户输入错误，不外泄 UnicodeEncodeError。 |

所有新选择 / 载荷错误均可通过现有未知可信错误 INTERNAL_ERROR 安全兜底，未要求 I03 为辅助函数新增公开能力、字段或方法。有限资源类别已经由 I03 草案覆盖；实际公共适配器待真实 I04 完成。固定细码是内部交接，不直接跨 bridge 输出原始异常链。

本修订的有限语义版本为 `i05-finite-3`：原完整推理载荷不变，投影视图修复了 `01` 等合法原词法被默认解析规范化的问题，并增加选中结果校验。不能用旧生产者版本冒充本版来源一致；具体兼容与历史隔离由外层按原策略处理。
