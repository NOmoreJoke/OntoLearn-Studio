# 凭据密文身份绑定：内审与验证

日期：2026-10-20。旧代码基准 `56de8312c72d8ec2dd7a6739ac01f5737e5914fe`；本轮仅修改 I06 专属凭据模块、专属测试和文档，不接入实际平台仓库。

## 复现与修复

旧边界只加密密钥，解密结果采用仓库 metadata 标记身份。四项新增测试实际失败：修改 metadata 的主体、修改版本、交换另一条有效密文、追加 metadata 未知字段。前三类可以返回错误配对或重标的凭据，最后一类会透传仓库额外字段。

现在加密 strict 内部信封 `{format:1,binding:{ref,principal,version},secret}`。读取时严格解析 metadata 和解密信封，核对请求 ref、主体、版本；只返回信封中已校验的身份和密钥。旧 raw-key、坏 JSON、未来格式、顶层及 binding 未知字段和非法密钥继续拒绝，无宽松降级。当前尚无实际持久凭据或发布格式，不需要把旧测试信封当作产品迁移输入。
