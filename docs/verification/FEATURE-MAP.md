## Reviewer B 使用说明

1. 根据 PR 命中的 Feature 行逐项核查「驱动 / 证明单元」是否真实执行且未删减断言。
2. 核对 Commit / `result.json` 的 `Verified:` 戳记，以及命中的 **Diff 触发式历史故障清单**（见 `VERIFY.md` §3）是否均有实测证据。
3. 发现的每条问题须标明 **`[Important]` / `[Nit]` / `[Pre-existing]`**。
